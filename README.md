# Supervisório para Estação de Tratamento de Água (ETA)
> **Projeto de Conclusão de Curso (TCC)**  
> Curso Técnico em Eletroeletrônica — SENAI  
> **Grupo 2**

Este repositório contém o código-fonte do **Supervisório e Dashboard Web** desenvolvido para o monitoramento e controle 
de uma maquete de Estação de Tratamento de Água (ETA) em escala reduzida.

O sistema recebe dados de sensores e envia comandos para atuadores físicos gerenciados por um microcontrolador **ESP32** 
via Wi-Fi/WebSockets, permitindo o acompanhamento em tempo real do processo de purificação.

---

## Tecnologias Utilizadas
* **[Vue.js](https://vuejs.org/)** — Framework JavaScript reativo para a interface web.
* **[WebSockets API](https://websocket.org/)** — Comunicação bidirecional e em tempo real com o ESP32.
* **[HTML5 / CSS3 / JavaScript]** — Estrutura, estilização e lógica de comunicação.
